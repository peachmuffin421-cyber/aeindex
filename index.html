§④ Æ Evolution vs NN — same ordered ticks, learning speed

Both learners see the same ordered ticks, in the same order, once. Æ: 1 exact SelfEvolution step per tick (Fraction, no gradient, no replay, no batch). NN baseline: epochs / tick gradient steps per tick on the same tick (last-8 deltas → next delta, MSE). Learning speed = ordered ticks to hold deviation ≤ 0.02 + δ accuracy ≥ 80% for 20 ticks. No batch wait, no epoch × dataset cost. Cyan = Æ deviation. Gold = NN loss (scaled). Green band = target.

      What is Æ? — tap to expand

      What it is

      Fusion of ÆI (Seedling) and ÆEA (market engine) — Final, First edition. Neither parent loses a function in the design. Display in this file caps and truncates for readability, so the display itself is not lossless. See Risk disclosure. Neither parent loses a function. Seedling stays the ÆI frontend. ÆEA stays the market engine. The fusion is the shared ordered feed + the selection loop that closes both.

      One ordered tick, two consumers

      1. Market tick → ordered tick — producer enqueues once; drain assigns ordered_index += 1 and consumes in arrival order.
      2. ÆEA OnTick / OnBar / OnPoint — tick → bars → 13 indicators + Ichimoku → m / n (only >66.6 / <33.3) / δ → ℛ_regime → BB×58 → 𝒫_arc → signal iff δ-gate → order / trailing / ℱ_VG.
      3. ÆI x from the same tick — x = Fraction(price-delta, scale) → prime → Λ₂₄ → Hopf → s² vs r² → deviation → DbZ → I → SelfEvolutionCore.evolve_step + 𝒪[Ψ].
      4. Selection closes the loop — δ-gate firing + deviation falling keeps that generation; deviation growing rectifies ψ and the next prime mutates the lattice.

      Why Æ is compared with NN learning speed

      NN must re-see data: epochs × dataset, gradients, replay, batch wait. Æ sees each ordered tick once and takes one exact step. Learning speed is measured in ordered ticks, not epochs. That is the whole comparison in §④ above. A win here is a win against the small toy baseline in this file, not a proof about neural networks in general.

      Backend wiring

      No backend URL is stored in this file. Supply it at runtime, in this order: window.AE_BACKEND_URL → ?backend= (read once, saved to localStorage, stripped from address bar) → saved localStorage → same-origin only if this file is served BY the backend itself. ?aei_backend= / ?aeea_backend= = legacy split backends, optional. UI never shows a URL, only ● connected / ● standalone / ● backing off. Without a supplied backend it runs standalone.

      Standalone

      With no backend it runs on a local synthetic market feed so every panel still works. Those numbers are toy numbers, not the real seed / real market.

      What it does NOT do

      • It does not run the backend seed loop itself. It does not compute backend seed values with floats.
      • It does not replace app.py / AEI_Seed / SelfEvolutionCore / ÆEA engine.
      • It does not talk to the crawler relay directly for seed x — crawler is fallback ordered source via backend.
      • It does not store a bot token or any secret. It only forwards the initData Telegram itself injected.
      • It does not store any backend URL — not plain, not base64, not encoded.
