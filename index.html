    What is the Seedling? — tap to expand

    What it is

    A toy / onboarding frontend skin for the ÆI Seed TWA — the GAIA / ÆI Codex seed. Not the ÆEA market bot. It lives in Repo A Frontend. This file IS the entry point. It replaces the old 11-panel view. It lives alongside index.htm (Codex Symbolica visualization) only.

    What it does

    It gives you a pet to care for. Each Feed a Prime sends POST /step with {x: '1/100'} to the backend. The backend then runs the real seed loop:

    1. Primorial / prime step — generate the next prime, exact Fraction.
    2. Lattice step — stereographic-project the prime, add a sphere to Leech lattice Λ₂₄.
    3. Wavefunction — integrate ψ over the lattice, blending with the prior rectified ψ so DbZ persists.
    4. Trajectory — generate the Natalia-fibrated quaternionic path.
    5. Aetheric gate — validate s² = r², compute deviation_sq.
    6. DbZ — if deviation ≠ 0, rectify ψ.
    7. Metric — record intelligence metric I.
    8. Evolution + Observer — SelfEvolutionCore.evolve_step + observer integral 𝒪[Ψ].

    It then polls GET /miniapp-state every 3 seconds and displays the backend’s values: primes tail, lattice points, psi_real, I, deviation, coherence, Hopf base.

    What it does NOT do

    • It does not run the seed loop itself.
    • It does not compute seed values with floats.
    • It does not replace app.py / AEI_Seed / SelfEvolutionCore.
    • It does not talk to the crawler relay directly. The Cloudflare Worker relay is a stateless fetch proxy; frontier logic lives in app.py, and crawled doc hashes become the next x.
    • It does not store a bot token or any secret. It only forwards the initData Telegram itself injected.

    Standalone mode

    When no backend is reachable, it runs a local simulation so you can still play. Those numbers are toy numbers, not the real seed. The Live Seed panel will say so.

    The pet layer

    Hunger / Energy / Bond / XP / speech / dialogue are gamification to make the loop feel alive. They are local only, stored in this browser’s localStorage, and have no backend counterpart.

    How it is wired

    Backend resolution: window.AEI_BACKEND_URL → ?backend= (read once, saved, stripped from the address bar) → localStorage['aei_backend_url'] → built-in default (base64, decoded at runtime). GET polls carry auth as ?auth_init_data=. POSTs carry X-Telegram-Init-Data. The UI shows only ● connected / ● standalone, never the URL.
