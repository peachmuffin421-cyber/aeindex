      What is AE? — tap to expand

      What it is

      Fusion of AEI (Seedling) and AEEA (market engine) — Final, First edition. Seedling stays the AEI frontend. AEEA stays the market engine. The fusion is the shared ordered feed + the selection loop that closes both. Display in this file caps and truncates for readability, so the display itself is not lossless. See Risk disclosure.

      One ordered tick, two consumers (backend)

      1. Market tick → ordered tick — backend producer enqueues once; drain assigns ordered_index += 1 and consumes in arrival order.
      2. AEEA OnTick — tick → bars → 13 indicators + Ichimoku → m / n (effective thresholds >69.33 / <30.66; max 14) / delta → regime → BB → P_arc → signal iff delta-gate → order / trailing / FVG.
      3. AEI x from the same tick — x = |price − prevPrice| / 10000 in the backend (or 1/100 when zero). Frontend never sends x → prime → lattice → Hopf → s2 vs r2 → deviation → DbZ → I → SelfEvolution step + observer integral.
      4. Selection closes the loop — delta-gate firing + deviation falling keeps that generation; deviation growing rectifies psi and the next prime mutates the lattice.

      Why AE is compared with NN learning speed

      NN must re-see data: epochs × dataset, gradients, replay, batch wait. AE sees each ordered tick once and takes one exact step. Learning speed is measured in ordered ticks, not epochs. A win here is a win against the small toy baseline on the backend, not a proof about neural networks in general.

      Backend wiring

      No backend URL is stored in this file. Supply it at runtime, in this order: window.AE_BACKEND_URL → ?backend= (read once, saved to localStorage, stripped from address bar) → saved localStorage → same-origin only if this file is served BY the backend itself. UI never shows a URL, only connected / WAITING / backing off. Without a supplied backend this page shows WAITING and posts nothing.

      WAITING

      With no backend, or with the backend unreachable, every panel shows WAITING. No bars, no price, no indicators, no seed values, no orders, no race values are faked locally. That is the whole point: WAITING is honest.

      What it does NOT do

      • It does not run the backend seed loop itself. It does not compute backend seed values with floats.
      • It does not replace app.py / AEI_Seed / SelfEvolutionCore / AEEA engine.
      • It does not talk to any exchange directly. Market data comes only via the backend.
      • It does not talk to the crawler relay directly for seed x — crawler is an ordered source via the backend.
      • It does not store a bot token or any secret. It only forwards the initData Telegram itself injected, in a header, never in a query string.
      • It does not store any backend URL — not plain, not base64, not encoded.
      • It does not train a local NN, does not generate local bars, and does not create local orders.
